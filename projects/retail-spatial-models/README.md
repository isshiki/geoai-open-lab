# 公開データによる商圏・アクセスモデルの検証

テーマID：`retail-spatial-models`。2026-10-07に[Issue #1](https://github.com/isshiki/geoai-open-lab/issues/1)を精査し、今後の研究候補として登録しました。**計画のみ。データ採用・取得・分析・精度検証は未実施です。**

[研究計画](docs/research-plan.md) / [出典・確認状況](docs/data-sources.md) / [共通データポリシー](../../docs/data-policy.md)

最初の問いは「公開された人口・店舗属性・移動コストで、店舗別の売上シェアを単純な比較方法よりよく説明・予測できるか」です。第一候補はニューヨーク州の宝くじ販売店データですが、一般小売の売上や来店人数とは区別します。

まず小さなデータ監査、その後に通常のHuffを検証します。CDMは追加効果を試す後続段階。Hansen型とHuff型2SFCAは生活サービスのアクセス評価として独立したケースへ分けます。改善しない結果、データ不足による見送りも成果です。

POI連載の「地域特徴量→類似地点→クラスタリング→Embedding」の予定を置き換えません。駅の縄張りの最寄り1駅への割当とも異なり、Huffは複数候補への確率的な配分を扱います。共通の実験05・06という番号は付けません。

現段階では環境、Notebook、コード、ダミー結果を作りません。着手時に専用のPython/uv環境と必要最小限の実装を追加します。新規データ・依存の取得は名前・URL・サイズ（不明なら明記）を提示して確認後に行い、成果物はGit管理外のテーマ内`data/`へ保存します。他チャット送信・記事公開・分析実行は、この計画登録には含みません。

Issue #1は引き継ぎ・計画登録の完了としてクローズしました。今後の計画の正本は本ディレクトリの文書とし、Issueは具体的な不具合や完了条件が明確な実装タスクに使います。
