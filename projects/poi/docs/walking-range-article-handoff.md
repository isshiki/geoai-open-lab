## 主な結果

範囲を変えると件数は変わるが、今回の円と徒歩10分の結果は大きく食い違ったわけではない。円の3,481件はすべて徒歩10分条件に入った。一方、正方形と徒歩10分は一方が他方を完全に含む関係ではなかった。

| 条件 | POI登録数 | 到達道路延長（m） |
| --- | ---: | ---: |
| 1km四方 | 3,591 | 対象外 |
| 半径500m | 3,481 | 対象外 |
| 徒歩5分（400m） | 2,141 | 14,991.694 |
| 徒歩10分（800m） | 3,794 | 49,583.567 |

道路延長は1本の経路の長さではなく、制限距離以内に到達できる道路部分の合計。接続線を除き往復も二重計上しない。徒歩時間は80m/分という仮定に基づく。

## 記事の構成案と掲載コード

1. 「駅周辺」を何のために決めるのか
2. 同じ駅代表点から4つの範囲を作る
3. 件数・構成・共通するPOIを見る
4. 直線と道路距離が異なる場所を確かめる
5. 到達圏にも条件と限界がある

```python
from geoai_open_lab.walking_range import run
from geoai_open_lab.walking_figures import figures
from IPython.display import SVG, display

summary, overlap, manifest, out = run()
display(summary[["condition", "poi_count", "road_length_m"]])
display(overlap)
figures()
display(SVG(filename=str(out / "ranges.svg")))
```

`run()`は固定入力の照合、道路への接続、最短路・各集合の集計・manifest保存を行う。初回のローカル入力指定とPNG生成コマンドは方法資料を参照。

## 言えること・言えないこと

- POI集合の違いは確認できた。一方、円と徒歩10分、正方形と徒歩10分では構成比や集合がかなり近いという結果も残す。
- 円500mと徒歩800mは距離閾値自体が異なるので、この差を道路の障壁の効果だけと解釈しない。
- 駅代表点は出口ではなく、直線接続が建物・線路などを横切る可能性がある。最寄りの辺が実際に使える入口とは限らない。
- 上流の最大連結成分抽出、OSMの道路タグ・欠落、POIの欠落・閉店記録、道路とPOIの時点差がある。
- 待ち時間・坂・階段の負荷・改札・混雑は含まない。徒歩80m/分は仮定であり、実際の徒歩分数を保証しない。
- 「徒歩10分で行けるカフェ」を今回の条件で数えることはできるが、現地確認済みの案内ではない。売上・需要・出店可否・住みやすさは判断しない。
- 正しい駅勢圏を決めず、吉祥寺1駅から一般化しない。Notebook 09のAOI拡大、10の固定外枠分割とも異なる検証。
