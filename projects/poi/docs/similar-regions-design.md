# 「吉祥寺」に似た街：分析前の固定設計

2026-10-15、今回のユーザー依頼に基づき固定。ランキングを見る前に記録する。
東京都内の駅の一括集計は類似地域検索の工程であり、独立した記事を追加しない。

## 入力と駅

- N02-25（2025-12-31基準、JGD2011）の旅客鉄道・軌道駅を使用。鉄道区分で追加除外しない。公式N02_005gで統合し、代表コードN02_005cが同値の駅線を使う。名称だけの統合なし。
- 代表線の結合、非連結なら最長線（同長WKT順）、EPSG:6677上の長さ中点は既存規則を維持。代表コードなし・不正geometry・不明な駅名は停止して監査する。
- 東京都N03-20260101_13のポリゴンが代表点をcoversする駅。境界点を含み、同名別グループ・非連結・都境界から1m以内を記録する。
- 全駅の代表点±500m。都境界で切らない。250m16区画、500m4区画。AOI間のPOI共有を許容。
- EPSG:6677はJGD2011 / 平面直角座標系第IX系の識別番号。東京周辺をメートル単位で扱うために使用する。
- Overture Places 2026-09-23.0 / v2.0.0。全AOIを覆う外接矩形から一度取得し、各正方形への割当は投影座標で判定する。LIMIT・サンプリング・country・営業状態・confidence除外なし。必要列とsources/licenseを保存。取得不能なら停止し別releaseへ変更しない。
- 全queryの正常完了・schema・ID・geometry・範囲・ハッシュを確認した入力のみ採用。同一ID同一内容の重複だけを除き、異なる内容の同一IDは停止。未取得は0件としない。
- schema version 1、display_groupsは既存設定のまま固定。吉祥寺も一括入力から再計算し、既存の固定入力による15列と照合してから類似度へ進む。

## 主指標と例外

密度と集中度の両方にlog1pを使用し、カテゴリ6列は生の構成比を使う。密度・カテゴリ6列・集中度の8列を、全対象駅の中央値とIQR（線形補間25/75百分位）で標準化。カテゴリ各列を1/sqrt(6)倍し、3ブロックのユークリッド距離を計算する。その他・欠損率・登録数・最大密度は投入しない。ブロックの実際の分散が等しいという意味ではない。

0件駅では構成比・集中度は未定義のまま特徴量表に残し、標準化母集団・ランキングから除外して一覧化する。正の件数なのに非有限特徴がある場合は停止。IQR=0の採用列が一つでもあれば停止し、結果を見て都合よく列を除かない。通常標準化も標準偏差（ddof=0）が0なら停止。

吉祥寺の距離0を検証して順位から除く。同距離はregion_id昇順。全駅候補順位を監査用に保持し、主順位では吉祥寺AOIとの重複面積が厳密に正の駅を除外（辺の接触のみは残す）。標準化の母集団から重複駅は除かない。中心間距離・面積・率を監査する。

## 感度確認と説明

同じ入力・候補駅・重複除外で以下を全て報告する。再スケーリング母集団は同じ。

1. 密度だけ（log1p＋robust）
2. 主指標（robust、3ブロック）
3. 平均・標準偏差への変更
4. 密度ブロックを除外
5. 集中度ブロックを除外

各トップ10、主順位との共通件数・Jaccard、順位差、各方式での距離を保存する。方式間の距離の絶対値は尺度が異なるため直接優劣比較しない。二乗距離を3ブロックへ分解し寄与率を計算する。距離0の寄与率は未定義（合計100%検査の対象外）とする。

正解ラベルはなく、精度や類似度パーセントを主張しない。景観・人口・住みやすさ・交通・地価を測っていない。順位はPOI収録差、選択特徴、格子配置、標準化・重みに依存する。
