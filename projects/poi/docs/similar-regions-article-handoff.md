# 記事引き継ぎ：「吉祥寺」に似た街

タイトル候補：**「吉祥寺」に似た街はどこ？　POIデータで東京都内の駅周辺を比べてみた**

実装・実測済み。ブログ原稿・投稿・公開は行っていない。[手順](similar-regions.md) / [検証](similar-regions-validation.md) / [Notebook](../notebooks/06_similar_regions.ipynb)。

## 読者へ伝える結論

東京都内656駅の1km四方を同じ数値プロフィールへ変換した。密度・構成・集中度で比べると町田・自由が丘・立川南が上位となり、密度だけのトップ10とは一致しなかった。ただし方式変更で候補が入れ替わる。見つけたのは選んだPOI特徴の近さであり、街の雰囲気や住みやすさの一致ではない。

## なぜ近く、何が違うか

- 町田：集中度3.7191倍は吉祥寺3.7427倍に近い。一方、登録密度は2,478対3,591件/km²、カフェ構成比は3.79%対5.54%で異なる。
- 自由が丘：カフェ5.22%対5.54%、衣料6.09%対6.68%が比較的近い。一方、美容等13.81%対8.94%で異なる。
- 立川南：バー7.32%対7.24%、集中度3.5862倍対3.7427倍。一方、食事30.31%対25.79%、密度2,610対3,591で異なる。

| 駅 | 密度の寄与% | 構成の寄与% | 集中度の寄与% |
| --- | --- | --- | --- |
| 町田 | 15.15 | 84.81 | 0.04 |
| 自由が丘 | 15.20 | 81.80 | 3.00 |
| 立川南 | 7.85 | 90.87 | 1.28 |

寄与率は二乗距離の内訳。「類似している確率」ではない。単一の特徴が近いことだけで順位を説明しない。

## 密度だけとの比較と安定性

密度のみのトップ10は三越前、京成上野、明治神宮前、神泉、築地、神保町、湯島、小伝馬町、新富町、新宿御苑前。主順位との共通は0件。

| 方式 | 主トップ10との共通数 | Jaccard | 比較候補数 |
| --- | --- | --- | --- |
| main | 10 | 1.0000 | 654 |
| density_only | 0 | 0.0000 | 654 |
| standard | 8 | 0.6667 | 654 |
| no_density | 6 | 0.4286 | 654 |
| no_concentration | 7 | 0.5385 | 654 |

通常標準化への変更では8件、密度なしで6件、集中度なしで7件が共通。順位を普遍的な街の評価として書かない。詳細順位差・方式別距離はCSVを参照。

## 重複除外

吉祥寺自身と、吉祥寺AOIに24.5932%重なる井の頭公園（中心間714.759m）を主順位から除き654候補。全駅順位は監査用に保持。

**候補同士のAOI重複は除外していない。立川南・立川北・立川は別駅グループだが近接した重なる地域であり、独立した3つの街の発見ではない。** 結果に合わせて統合・除外しない。

## 記事に載せる核心

```python
from geoai_open_lab.tokyo_region_features import run_comparison
profiles, rankings, stability, manifest, output_dir = run_comparison()
rankings["main"].dropna(subset=["rank"]).head(10)
```

実装内部の核心は次の計算。密度・集中度のlog1pを先に適用し、全有効駅で列ごとに計算する。

```python
z = (features - features.median()) / (features.quantile(.75) - features.quantile(.25))
delta = z - z.loc[kichijoji_id]
distance = (delta[density_col]**2
            + delta[category_cols].pow(2).sum(axis=1) / 6
            + delta[concentration_col]**2)**.5
```
