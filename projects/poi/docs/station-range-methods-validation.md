# 駅周辺を定義する3方式：方法・追加検証

Notebook 11・11bとは独立した検証スクリプトを追加した。既存Notebook・コード・保存結果は書き換えない。[記事引き継ぎ](station-range-methods-article-handoff.md)が今回の記事用の正本。

## 固定条件

- 対象656駅、駅代表点・EPSG:6677・Overture `2026-09-23.0`・固定OSM `kanto-261001`を維持。
- 11bの駅別POI判定を読み、1km四方、直線500mの円、道路距離500mの3対を計算。
- Jaccard=共通数/和集合数、件数差=第2−第1、TVD=8分類の構成比差の絶対値合計/2。構成比の分母は各条件の全POI登録数。その他・欠損を含む。
- 各カテゴリの差もポイント単位で保存。全駅と和集合30件以上を分け、30件未満も消さず残す。和集合0件ならJaccardは未定義、片方が0件ならTVDは未定義とする。
- 今回の3条件は道路500m⊆円500m⊆正方形の包含関係。Jaccardは小さい集合/大きい集合の件数比と一致する。件数比とは別の独立した証拠ではない。
- 正方形は1km²、円は約0.785km²、正方形の角は約707m。形だけを変えた同面積比較ではない。道路到達範囲のポリゴン面積は求めない。
- 道路距離は駅接続＋道路上距離＋POI接続。双方100m上限。速度はこの500m判定自体には使わず、80m/分なら約6分15秒という換算になる。実歩行時間を計測していない。
- 新宿 `n02-003700` を主例、吉祥寺 `n02-003584` を対照。どちらも11bの事前指定駅だが、今回の主例選択は11bの結果を見たユーザー指定である。新宿が全駅の代表標本とは説明しない。

## 解釈の限界

駅出口、改札、地下通路・屋内通路の網羅性、通行規制、OSM欠落、駅代表点と実際の出入口のずれを検証していない。道路へ最短でつなぐ線が実際に歩けるとは限らない。坂・階段・信号・混雑や個人の歩行速度は未考慮。経路モデルを現地の正解にしない。

POI登録数は営業中店舗数・需要・売上ではない。近接駅の対象範囲は重なるため656の独立標本ではない。古典的MAUPのゾーニング効果を分離した実験ではなく、分析範囲の定義に対する感度を確認する。UGCoPとの位置付けは[事前設計](walking-sensitivity-design.md)を参照する。

## 完了検証

既存分を含む154テスト成功（76.503秒）。全656駅の3比較について、POI IDの集合演算から共通数・和集合・Jaccardを独立に照合し、カテゴリの相対頻度からTVDを再計算した。直線500m対道路500mは11bの既存値と一致。空集合、無効接続、低件数の境界をテストした。

5種類のSVG/PNGを生成し、SVGの文字外枠越え検査・全図・800px幅カバーを目視確認。図のJaccardが生成CSVと一致し、SVGの再生成ハッシュも同じ。Notebook 11・11bと既存成果物は保存時のハッシュと照合して不変。新規Notebook・依存・ダウンロードは追加していない。
