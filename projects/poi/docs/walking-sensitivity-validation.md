## 再現コマンドと成果物

`projects/poi` で実行。既存uv環境・既存入力が必要。取得処理を呼ばない。

```powershell
$env:UV_CACHE_DIR = Join-Path $PWD 'data/cache/uv'
uv sync --locked --offline --group osm --group clustering --group notebooks
uv run --no-sync python -m geoai_open_lab.walking_sensitivity --road-dir <固定道路ディレクトリ>
uv run --no-sync python scripts/verify_walking_sensitivity_replay.py --road-dir <固定道路ディレクトリ>
uv run --no-sync python scripts/execute_walking_sensitivity_notebook.py
node scripts/render_walking_sensitivity.cjs
```

CLIの代わりに `GEOAI_OSM_ROAD_DIR` も使える。nodes/edgesの固定ハッシュを検査する。ブラウザ描画は既存Playwright/Edgeを使用、必要なら `BROWSER_EXECUTABLE` と `NODE_PATH` を指定する。自動インストールしない。

Git管理外 `data/cache/walking_sensitivity/tokyo-v1/`:

- `stations.csv`: 有効性・接続距離・候補数・接続不成立数
- `conditions.csv`: 全7条件の件数・8カテゴリの件数と比率
- `comparisons.csv`: 全8比較・656駅の共通数・Jaccard・件数差・構成差
- `distributions.csv`: 全駅/30件以上/低件数の分布
- `controls.csv`, `examples.json`: 事前指定/規則選択の例
- `stations/*.parquet`: 監査用の各POI対応（非公開）
- `manifest.json`: ハッシュ・環境・11との照合・事前設計ハッシュ
- `replay-validation.json`: 全駅再実行の照合結果
- SVG/PNG、出力付きNotebook、HTML、Apache LICENSE、Foursquare NOTICE

[データポリシー](../../../docs/data-policy.md)と[方法の出典・限界](walking-sensitivity-design.md)に従う。外部データのライセンスをApacheに変更しない。
