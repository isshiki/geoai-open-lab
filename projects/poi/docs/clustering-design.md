# 地域特徴量クラスタリング：分析前の設計

2026-10-16、分類結果を見る前に固定。新しいPOI・駅データは取得しない。

- 入力は `data/cache/similar_regions/tokyo-v1/` の656行15列と駅表。前回manifestのSHA-256と各CSVハッシュを設定で固定し、ID対応・件数・非有限値を検査する。
- 前回と同じ密度・集中度のlog1p、6カテゴリ構成比、全有効駅の中央値/IQR（線形補間）、カテゴリ各列を1/sqrt(6)倍した8次元。その他・欠損・ID・座標等は投入しない。0件は未定義として停止し、今回656駅の主分析を黙って縮小しない。IQR=0・非有限値も停止。
- K-means++、Lloyd、n_init=30、max_iter=500、tol=1e-4。基準seed=42。k=3〜8をすべて比較。seed=0〜9の各30初期化と基準のARI、および各seed間のARIを保存する。全指標は8次元で算出する。
- silhouette（高い方）、Calinski-Harabasz（高い方）、Davies-Bouldin（低い方）、慣性、全クラスタ件数、最小件数を報告。20駅未満の群を小群としてフラグするが除外しない。主kは指標だけで自動決定せず、規模・安定性・特徴の説明可能性を比較後に理由付きで選ぶ。候補が全て不安定ならそのまま報告。
- 各kでWard法を比較し、基準K-meansとのARIを記録。採用kではクロス表も出す。
- 表示番号はクラスタの生の密度中央値の昇順、同値は所属region_id最小値の順。優劣ではない。代表駅は8次元の重心へ近い所属駅3件（同距離ID順）、異なる例は最も遠い所属駅。地理的中心ではない。
- 特徴説明は生の中央値、群平均−全駅平均、変換後群平均−全駅平均を保存。後者の絶対値上位を分類差の説明とする。因果的な重要度とは呼ばない。
- 全656駅を主分析に残す。全駅ペアで正のAOI重複面積を監査し、同群率・群別重複関与数を出す。感度確認ではregion_id昇順の貪欲法で既採用AOIと正面積で重なる駅を抑制。特徴や結果は選択に使わない。尺度は全656駅のまま、同kで再学習し全656駅を最寄り重心へ割当、ARIと対応表を記録。これは独立標本を保証せず順序依存の感度確認である。
- PCAは同じ8次元を平均中心化して表示するだけ。full SVDの2軸と寄与率・累積寄与率を保存し、入力の次元圧縮・Region Embeddingとは区別する。
- 生データ・CSV・図・HTML・manifestはテーマ内Git管理外。前回の出典・利用条件・NOTICEを引き継ぎ、加工日を追記する。出典条件は[前回設計](similar-regions-design.md)、[出典](region-feature-sources.md)。

公式実装資料（2026-10-16参照）：[KMeans](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.KMeans.html)、[クラスタリングと評価](https://scikit-learn.org/stable/modules/clustering.html)。乱数seedや初期化回数を明示して既定値への依存を避ける。
