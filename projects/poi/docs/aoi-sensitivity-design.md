# 正方形AOIの感度検証：分析前の固定仕様

2026-10-17。既存結果を上書きしない。EPSG:6677、N02-25の656駅、Overture 2026-09-23.0、primary語彙961列を維持。半幅500/600/700/800mで比較する。

- 500mは旧候補除外で記事の全順位・距離、特徴量、A/Cクラスタ所属を照合してから比較する。新しい主比較は全照会駅について800m同士が正面積で重なる駅を共通除外。同距離はregion_id順。記事と主比較の候補集合は別。
- Aは各AOIでlog1p密度・集中度、6構成比を再計算し、全656駅の中央値/IQRとカテゴリ1/√6で再標準化する。格子は駅から西南500mを原点とする既存250m格子を拡張し、端は実面積を分母にする。端の小区画による最大密度への影響を監査する。境界は内部で東・北、外縁は内側へ一意割当。
- Bは保存済み語彙の順序を固定、件数TF・smooth IDF・L2。新たな語彙外primaryは除外数を記録。Cは各AOIでBを再学習したSVD64（seed42/n_iter10）からL2。成分番号をAOI間で比較しない。
- 全順位のSpearmanは共通候補の距離の順位（同距離は平均順位）から計算する。上位10の共通数は0〜10。平均・中央値・分布・駅別値を保存し、上位10内の順位相関と混同しない。
- Cのk=3（既存K-means設定）を500mと比較し、ARIと最大一致対応後の変更数を報告。A/Bも同じk=3で参考比較。代表駅は各群の中心へのユークリッド距離順、同距離はID順。
- 変化の大小は共通数、Spearman、IDで決定。追加カテゴリは同時に増えたものとして扱い因果としない。近接ペアの共有POI率と類似度を別監査し、独立した街の発見と扱わない。
- 原点を保つ部分格子の定義、IDF・標準化・SVDの再学習も含むパイプライン感度であり、範囲だけの局所的効果とは限らない。

## 取得範囲の不足

既存531,156件は全駅500m AOIを覆う外接緯度経度矩形の全件。東京都境界による切落しなし。800mでは古里・奥多摩・篠崎・南町田グランベリーパークが矩形をはみ出す。4駅の800m AOI内かつ既存矩形外の部分だけ同releaseから追加取得する。既存入力は変更しない。LIMIT・国・営業状態・confidenceで除外しない。sources/licenseを維持し、取得量と通信量は区別する。取得失敗時は別releaseで補わない。
