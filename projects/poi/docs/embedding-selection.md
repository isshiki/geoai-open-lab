# 主結果の次元数（2026-10-17）

初回の次元比較を終え、駅名によるストーリーや図を作る前に64次元を主結果とした。
8/16/32/64次元の累積説明分散は38.9/48.1/58.9/71.3%、Bの近傍10駅保持率は28.7/40.7/51.1/63.9%。
POIを相補的に半分へ分けた近傍一致は23.4/24.9/25.8/26.8%で、Bの30.2%より低かった。
seed変更の一致は100.0/99.6/97.7/96.5%で、小さい次元ほど良い。

64次元を選ぶ理由は、候補内で元のカテゴリ近傍を最も保ち、分割時も最も良かったため。
961列を64列に縮めるが、失う近傍も多い。計算は全候補ともこの環境で1秒未満で、速度優位を採用理由にしない。
これは探索した候補内の選択で、別データに対する最適次元の証明ではない。
圧縮しないBを上回る安定性は確認できず、Embeddingの優位性は主張しない。

比較仕様は[設計](embedding-design.md)、全数値は[検証](embedding-validation.md)を参照。
