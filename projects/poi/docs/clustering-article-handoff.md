## 結論の書き方

656駅のPOI特徴を3群へまとめた。密度が低めの群、局所的な集中が高い群、密度と食事比率が高めの群として説明できた。ただし明確に切り離れた3種類の街があるとは言えず、重複AOIの抑制で分類は大きく変わった。この限界も記事の主結果にする。

k=3を粗い入口に採用。全群165駅以上、seed間ARI最小0.9749、解釈の簡潔さを優先。指標を最大化した唯一の最適解とは書かない。k=4/5では衣料比率中央値13.41%の15駅群が見える。細分化に意味がないのではなく、主結果3群ではこの違いが薄まる。

Ward ARI0.6394。AOI重複1,186ペア、同群64.25%。ID順の非重複313駅で再学習すると全656駅のARI0.2707（313駅だけでは0.2035）。seedの再現性と、別条件にも通用する頑健性は別物である。

## 意外だったこと・同群の例外

- POIが多いことと局所集中の高さは同じではない。高密度C3の集中度中央値は2.628倍、中密度C2は4.268倍。
- C1の石神前はPOI10件に対しカフェ比率20%。少数登録で率が大きくなる例。
- C2の高松は集中度8.418倍、衣料16.62%。C3の明治神宮前は衣料20.52%・食事13.43%。群の名前を全所属駅へ一律に当てはめない。
- 地図では高密度群が東側に多く、他群も混在する。行政区・都市構造の原因は検証していない。

全列の中央値、全体平均との差、強い特徴は`cluster_features.csv`と`cluster_summary.csv`を参照。密度は件/km²、集中度は倍、構成比は0〜1（記事では%）。

## 掲載コード

```python
from geoai_open_lab.region_clustering import run_clustering
metrics, manifest, output_dir = run_clustering(k=3)
metrics[["k", "silhouette", "calinski_harabasz", "davies_bouldin"]]
```

核心は以下（説明用断片、完全な入力検証はライブラリ側）。

```python
z = (features - features.median()) / (features.quantile(.75) - features.quantile(.25))
z[category_columns] /= 6 ** .5
labels = KMeans(n_clusters=3, n_init=30, random_state=42,
                max_iter=500, tol=1e-4, algorithm="lloyd").fit_predict(z)
```

`features`の密度と集中度には先にlog1pを適用する。PCA座標をfit_predictへ入れない。

## 出典・限界

Overture 2026-09-23.0・取得2026-10-15、N02-25、N03-20260101_13。今回のデータ新規取得なし。出典条件は[方法](clustering.md)を参照。

- POI登録の分類であり、営業中店舗数・人出・住みやすさ・優劣・Tierではない。
- 1km四方は公式の街域、商圏、駅の縄張りではない。駅入口も表していない。
- 同名別グループ・重複AOIを含み、656個の独立した街を発見した意味ではない。
- その他・欠損率は距離に入れていない。前回のその他34.04〜100%、欠損0〜14.29%という収録上の限界を引き継ぐ。
- 人口、地価、景観、交通利便性を含まない。密度・カテゴリ・集中度、標準化と重みは分析上の選択。
- PCAの累積寄与率は65.95%。表示していない約34%があり、2次元の見栄えで分類の正しさを判断しない。
- 低件数では構成比が少数の登録に大きく左右される。主分析から事後除外しない。
- 現地正解ラベルがなく、ARIは分類同士の一致であって精度ではない。seed安定性だけで頑健と書かない。
