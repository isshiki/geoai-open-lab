- `python -m unittest discover -s tests -v`：75件成功（既存65件＋地域特徴量10件）。Foursquare・Overture・OSM・比較の既存テストを含む。
- 新規テスト：境界一意割当、外周包含、負座標、端の面積・密度、0件の未定義構成比、カテゴリ分母・alternates非展開、未取得停止、250/500mの一致、ID重複・範囲外・非有限値の拒否、表示対応重複、入力ハッシュ不一致。
- 最初のテストでは既存テスト2件がシステム一時フォルダの権限で失敗。TEMP/TMPをテーマ内 `data/cache/region_features/tmp` に指定して全75件成功。既存テストの内容は変更していない。
