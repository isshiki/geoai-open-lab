# 主結果の選択記録

2026-10-16、[事前設計](clustering-design.md)に従いk=3〜8を比較した後、主結果を **k=3** にした。これは唯一の正解ではなく、記事の入口としての粗い分類である。

- k=3は244・247・165駅で、20駅未満の小群がない。密度、食事構成、集中度の違いで3群を説明できる。
- seed間ARI最小0.9749・中央値1.0000で、比較候補内では最も安定している。
- CHはk=3が194.44で最大。一方silhouette最大はk=4（0.2345）、DB最小はk=5（1.2176）。指標は一致しない。k=3のsilhouetteは0.2260・DBは1.5141で、これらの指標では最良ではない。
- k=4では15駅の衣料構成比が高い群（中央値13.41%）が現れ、k=5でも残る。小さいだけで無意味とは判断しない。主結果を粗くしたため失う具体的な特徴として記事に残す。
- k=6〜8では小群が2つとなり、seed間ARI最小も0.9246→0.7608へ下がる。今回の短い記事では細分化を主結果にしない。
- いずれのsilhouetteも約0.21〜0.23で、自然に明確な境界を持つ街種が発見できたとは書かない。8次元の連続的な違いを便宜的にまとめたものとする。

クラスタ番号は密度中央値順であり順位ではない。仮称は設定`clustering-presentation.json`に記録する。低め・高めは今回の656駅に対する相対表現であり、全国や全市街地の基準ではない。地図・PCAはこの選択後に作成し、見栄えをkの選択条件にしない。
