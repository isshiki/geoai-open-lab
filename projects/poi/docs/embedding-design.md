# 地域Embedding：分析前設計

2026-10-17、入力schemaを確認後、順位・埋め込み結果を見る前に固定。

- 前回の656駅、1km四方、Overture 2026-09-23.0を変更しない。raw manifestとParquet、656行特徴量・駅表、前回クラスタ所属をSHA-256で照合。新規データ取得・依存追加なし。uv管理環境を使用。
- 保存済みtaxonomy.primaryを使用。1 POI=1 primaryカテゴリ。hierarchyは祖先重複を避けるため展開しない。alternatesは登録によって複数付与の程度が異なるため主分析に入れない。欠損をカテゴリにせず件数・率を別記する。POI名・チェーン名は使わない。
- 656駅のうち5駅以上に現れるカテゴリのみを採用（df>=5）。語彙は辞書順で固定。重複AOIもdfに影響するため監査する。稀少カテゴリをその他へ足さない。語彙除外率・欠損率・ゼロベクトルを記録。主入力でゼロベクトルがあれば停止し無理に順位化しない。
- Bは件数tf、smooth idf=log((1+656)/(1+df))+1、sublinear_tf=False、L2正規化。CはBを非中心化TruncatedSVD（randomized、n_iter=10、seed=42）で8/16/32/64次元へ圧縮後L2正規化。次元>=min(行数,列数)は不採用理由を記録。
- Aは前回の8特徴・log1p・中央値/IQR・カテゴリ1/√6・ユークリッド距離を再計算して既存順位と照合。B/Cはコサイン距離。距離の絶対値を方式間で比較しない。
- 主検索は吉祥寺自身と正面積でAOIが重なる駅を除外。全駅の近傍保持・安定性も各照会駅と重なる候補を除外し、上位10の共通率を使う。同距離はregion_id順。全順位・順位差も保存。重複を許した近傍との違いは別監査。
- 次元選択は説明分散・B近傍保持・5回のPOI分割安定性・次元間順位・計算時間を比較後に理由を記す。見栄え・街名は選択に用いない。B自体の分割安定性も必ず示す。
- POI ID順の全件をseed=100〜104で独立Bernoulli(.5)の相補2群へ分割。同じPOIが複数AOIに入る場合は必ず同じ側。語彙だけ固定し、各半標本でIDFとSVDを学習し直す。ゼロ行は評価不能として記録し、両側有効な共通候補のみで比較。低件数区分は全POI数<50、50〜199、200以上を先に固定。完全入力で得た語彙を使う条件付きの頑健性で、外部予測精度ではない。
- SVD seed=0〜4の変化を全次元で比較。重複抑制は前回と同じID順貪欲法の313駅でIDF/SVDを学習し、全駅へ変換。尺度・語彙は主条件と明示して比較する。
- 採用Cでk=3 K-means（前回と同じseed42/n_init30等）。前回分類とARI・対応表・最大一致対応後の変更例を保存。群番号は生密度中央値順で優劣なし。Silhouetteは球面上のコサイン距離を主表示し、K-means目的に合わせユークリッド版も保存。DBはユークリッド。Aとの値比較は空間も距離も違うため優劣の証拠にしない。
- 潜在軸は番号で示し、正負の上位寄与カテゴリを併記。任意の軸符号に固有の意味を付けない。C近傍の説明はBのカテゴリ積とCの逆射影によるコサイン内積分解（負の寄与も含む）を分ける。密度は別の監査列で、Cに直接投入しない。
- PCAは前回8特徴の表示専用。今回は非中心化SVDで多数の細分類を圧縮し、圧縮ベクトルを検索・分類に使う。両者は特異値分解に関係するが入力・中心化・利用目的が違う。外部モデル・深層学習を使ったとは説明しない。
