## 市域と駅候補

- N03_007の13203・13204と市名をCP932で照合。2 Polygon、欠損・空・不正geometryは0。入力CRSはEPSG:6668（JGD2011）、距離用はEPSG:6677。市域全体は第1次メッシュ5339に収まります。
- 市域の5,000m bufferを覆う道路取得候補bbox（WGS84、west/south/east/north）：
  `[139.46886937455685, 35.614716614327996, 139.65092107448837, 35.767230073944035]`。これは分析AOIではなく取得範囲です。
- 全国N02の駅線形10,267件はLineString。路線別中点をEPSG:6677上で計算し、buffer内98件。採用コード条件による除外0。コード組は11/2:20件、12/4:76件、21/4:2件。
- 中点座標は94種類。98件を実駅98駅とは呼びません。座標重複だけで駅を統合していません。2020年版に駅グループコードはなく、グループ感度確認用の対応は未確定です。

## 未確認事項と次段階

1. 人口表の不詳補完方式。通常メッシュの総人口との差は監査できたが、作成方式の公式説明との照合が必要。
2. 2020年1月市域と10月人口の間の境界変更、および12月駅と10月人口の時点差。
3. N03同梱メタデータは旧利用規約と測量成果の複製承認に言及。現行配布案内との関係と外部図版の手続を確認するまで境界図・派生境界データを公開しない。
4. 未掲載8メッシュとAOIをまたぐ合算単位の扱い。未掲載と秘匿を混同しない。
5. 道路の版・列・通信量見積り・実行上限を提示して別途承認を得る。道路・駅入口は今回取得していない。

今回の入力監査で、駅から遠いほど高齢化率が高いかどうかは判断できません。

## ローカル記録と公開安全性

`data/raw/station_access_aging/` に3ZIP、`data/cache/station_access_aging/` に取得manifest・入力監査JSON・監査CSV・駅候補Parquetを保存。全てGit管理外です。公開文書には集約した監査件数と再現情報だけを記載しています。取得・監査はAPIキー不要で、会社の非公開資産は参照していません。

オフラインテストは既存実験を含め68件成功。新規4テストはメッシュの四分割、合算参照の不一致、秘匿年齢をゼロにしない扱い、危険なZIPパス・重複名の拒否を架空データで確認しました。
保存済みZIPだけを使うローカル用 `input-audit.ipynb` の全セル実行と `input-audit.html` 生成も成功しています。両方とも上記cache内に保存し、公開用Notebookには追加していません。
