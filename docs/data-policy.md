# データポリシー

このリポジトリは、個人ブログと連動する独立したPublicプロジェクトです。公開取得可能なデータだけを扱います。公開されていることと、自由に再配布できることは別です。

## 会社との境界

**会社GeoAI（非公開）→ geoai-open-lab（個人公開）は禁止です。** 会社の非公開コード、ロケスマDATAなどの非公開・商用データ、社内ドキュメント・プロンプト・設定ファイル・Gitリポジトリ、社内でのみ利用可能なロジックやノウハウを参照・移植しません。会社資産を調査して個人側の設計に使うことも行いません。

**geoai-open-lab（公開）→ 会社GeoAIの参照・業務利用は可とします。** 会社側から公開コード・調査結果・ブログ記事・ドキュメントを参照できます。ただし各ライセンスへの準拠は必要です。この許容は逆方向の情報移転を認めるものではありません。

## Gitへ保存するもの

取得・検証コード、手順、公開可能な設定、データの版や取得条件を記した文書を保存します。生データ、ダウンロード済みParquet / GeoParquet / PBF、DuckDBなどのDB、キャッシュ、認証情報、`.env` は保存しません。生成物はこのプロジェクト内のGit管理外 `data/` に置きます。

小さなサンプルも、公開・再配布が明確に許可されている場合のみ `samples/` に追加できます。出典、許諾根拠、Attribution、加工内容を隣接文書へ記載してください。集計値・地図・Embeddingなどの派生成果も、元データの条件を確認してから公開します。

## データソース追加時の記録

最初の取得前に `docs/` にソース別文書を作り、次を記録してください。未確認項目は未確認と明示し、確認が済むまで取得・公開を進めません。

| 項目 | 記録内容 |
| --- | --- |
| データセット | 正式名称、提供者、公式配布URL |
| 利用条件 | ライセンス名・版、公式規約URL、確認日 |
| Attribution | 必須の表記と掲載場所 |
| 再配布 | 生データ・抜粋・加工物・集計・Embeddingの条件 |
| データの固定 | release ID / version、snapshot date（未提供ならその旨） |
| 取得 | 取得日時（UTC）、公開URL、提供チェックサムまたはローカルSHA-256 |
| 対象範囲 | AOI、座標参照系、フィルター、列、件数制限 |
| 再現手順 | 実行コマンド、コードのcommit、Python / DuckDBの版、uv.lock |

未提供の版情報を推測で埋めず、取得日時やチェックサムなどで補足してください。署名付きURL・認証情報は記録しません。ローカルの詳細な取得記録は `data/` 内に保存し、公開する文書には安全な再現用メタデータだけを転記します。

## 追加・コミット前の確認

1. `git status --short --untracked-files=all` と `git add --dry-run .` で候補を確認する。
2. 各候補の内容とサイズを確認し、生データ、秘密情報、不要な巨大ファイルを除く。1 MiB超は必ず理由を調査する。小さいファイルでもデータや秘密情報は許容されない。
3. Notebookは出力・実行番号を消し、metadataやattachmentsも確認する。
4. 確認済みファイルを明示して追加し、`git diff --cached --stat`、`git diff --cached --name-only`、`git diff --cached` を再確認してからコミットする。

`.gitignore` は補助であり、秘密情報検査の代わりにはなりません。`git add -f` で迂回しないでください。
